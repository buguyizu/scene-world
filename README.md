# scene-world

Standalone Vue 3 + Vite project with page navigation for the Orbital Resonance scene and a new 3D scene workspace.

Use the navigation links to switch between **Orbital Resonance** and **New Scene**. The new scene page is a workspace for adding the next 3D scene.

## Run locally

```sh
pnpm install
pnpm dev
```

Open the local URL printed by Vite. To create and preview a production build, run `pnpm build` and `pnpm preview`.
